Juego por turnos sobre una grilla N×N con salones, pasillos y paredes, donde un Policía persigue a un Bandido y este intenta evadirlo el mayor tiempo posible. Incluye la estrategia del Policía (Police.c), que calcula el camino más corto hacia el Bandido, y la contra-estrategia del Bandido (Bandit.c), que busca ciclos en el grafo del escenario para huir indefinidamente. Trabajo de Algoritmos y Estructuras de Datos II, FIUNI
